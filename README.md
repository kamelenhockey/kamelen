# GCHC Kamelen

Teamsite van GCHC H13 – de Kamelen. Live op https://kamelenhockey.github.io/kamelen/

- `competitie.json` – programma, uitslagen en stand. Wordt elke zondagavond automatisch bijgewerkt vanaf hockey.nl.
- `liters.json` – literklassement. Wordt elke donderdagavond automatisch bijgewerkt vanuit de spreadsheet.
- `opstelling.json` – wie er meespelen. Pas dit zelf aan vóór de wedstrijd (potloodje rechtsboven op GitHub).

Handmatig bijwerken: tabblad **Actions** → kies de workflow → **Run workflow**.
